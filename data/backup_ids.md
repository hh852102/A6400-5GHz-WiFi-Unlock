# Backup 属性参考表（ILCE-6400）

通过系统自带 `/usr/bin/bk.elf` 接口读写并保存，**不要**直接十六进制编辑持久化配置文件；写入后需执行 `/usr/bin/bk.elf s` 保存。

| 属性 ID | 默认参考值 | 研究目标值 | 说明 |
| --- | --- | --- | --- |
| `0x00A50006` | `09` | `02` | NVRAM 索引 → 对应 `bcm4339_H_%02d.txt` / `L_%02d.txt`（`09` 为仅 2.4 GHz 监管表，`02` 含 36–64 / 149–165 5 GHz 信道） |
| `0x01071563` | `01` | `01`（保持） | High (`01`) / Low (`00`) NVRAM 组选择 |
| `0x013E0022` | `01,01` | `02,95` | P2P GO 的 `[band, channel]`；`02`=5 GHz，`95`=149 信道（`0x24`=36 信道） |
| `0x013E003A` … `0x013E004B` | `01` | `01` | 18 个 5 GHz 信道使能标志位 |
| `0x00A50008` | `00` | `00`（不动） | 外部固件路径开关 |
| `0x00A50007` | — | 不动 | STA 路径配置索引 |

## 常用查询与设置命令参考

```sh
# 读取
/usr/bin/bk.elf r 00a50006 01071563 013e0022 013e003a 013e004b

# 写入
/usr/bin/bk.elf w 00a50006 02
/usr/bin/bk.elf w 013e0022 02 95

# 保存
/usr/bin/bk.elf s
```

## 注意事项

- `bk.elf` **无论成功与否均返回 255**，脚本不可依赖其退出码，也不可在 `set -e` 下直接调用。
- 保存操作涉及 `vfat` 同步，连续写入多个属性可能耗时数秒，可通过 `bk.elf r` 回读核对结果。
- 恢复默认配置：`w 00a50006 09`、`w 013e0022 01 01`、`bk.elf s`。
